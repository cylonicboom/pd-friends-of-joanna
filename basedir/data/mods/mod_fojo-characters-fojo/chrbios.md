# mod_fojo-characters-fojo bios

Source of truth for this mod's character bios. Edit here, then run
`tools/mkchrbios build-mod basedir/data/mods/mod_fojo-characters-fojo` to
write them into `modconfig.txt` as `ChrBio` blocks.

Each bio is keyed by the head it belongs to (`head`), not by a slot. A bio
for a vanilla head (`head_dark_combat`) replaces that character's built-in
one while this mod is mounted.

Inside a bio, `###` becomes a `|Heading -` section and everything else is
emitted verbatim — **a line break in this document is a line break in the
game**, so keep a paragraph on one line unless you mean to wrap it.
