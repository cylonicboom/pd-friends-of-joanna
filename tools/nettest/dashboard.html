what a run proves. a host and N clients boot from the CLI, the host arms a Team Mission (--team --team-roles) and starts it when the lobby fills; every process logs team/seat/netcl lines once a second. the verdict pairs those by net tick:
  • boot · connect · stage — server/client start, every client reaches CLSTATE_GAME, every process loads the armed stage with isteam
  • roles — the seat manifest is identical everywhere; each client sits in a non-operative seat whose role matches what the host armed
  • gameplay — the intro cutscene ends (tickmode 1) on every process, and every walker-driven pawn actually covers ground
  • agreement — per seat, each client sample within 120 units (p90) of the host's path, and health p90 within 0.1
  • stability — no crash, watchdog stall or guard trip in any log; no unexpected WARNING: NET; the prop auditor never says FAIL; tick drift bounded
